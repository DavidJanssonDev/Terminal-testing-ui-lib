# Support

Thank you for your interest in **Terminal Testing UI Library**.

This project is an **open-source, learning-focused UI framework** and is currently maintained on a best-effort basis.

---

## Getting Help

If you need help or have questions, please use the following options:

### 💬 GitHub Issues

- Use **Issues** for:
  - questions about how the system works
  - unexpected behavior
  - bugs
  - feature discussions

Please check existing issues before opening a new one.

### 💡 Feature Ideas

If you have an idea for an improvement or new feature, please open an issue using the **Feature Request** template.

---

## What Support Is *Not* Provided

- No guaranteed response time
- No private or commercial support
- No SLA (Service Level Agreement)

This helps keep expectations clear and sustainable.

---

## Philosophy

This repository exists primarily to:

- explore terminal rendering and UI architecture
- document learning and experimentation
- serve as a reference for others interested in similar systems

Constructive discussion and thoughtful questions are always welcome.

---

Thanks for checking out the project! 🚀

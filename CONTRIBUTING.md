# Contributing

Thanks for your interest in contributing to **Terminal Testing UI Library**!

This project is both a learning exercise and a foundation for a real terminal UI framework, so thoughtful discussion and clear changes are highly appreciated.

---

## Getting Started

### Prerequisites

- .NET 8 SDK (or .NET 6+)
- Windows Terminal or another ANSI-capable terminal
- Windows 10/11 recommended

### Build the project

```bash
dotnet build
```

### Run the demo

```bash
dotnet run
```

---

## Project Philosophy

- Prefer **clarity over cleverness**
- Avoid premature optimization (except in the rendering backend)
- Keep architecture decisions explicit and well-documented
- Rendering, layout, and UI logic should stay cleanly separated

---

## Coding Guidelines

- Follow existing code style and formatting
- Comment non-obvious logic (especially rendering/layout code)
- Avoid large refactors without discussion
- Keep pull requests focused on a single concern

---

## Reporting Bugs

Please use the **Bug Report** issue template and include:

- steps to reproduce
- terminal used
- .NET version
- screenshots or recordings if visual

---

## Feature Requests

Feature ideas are welcome!  
Please use the **Feature Request** issue template and describe:

- the problem being solved
- proposed behavior
- possible impact on existing APIs

---

## Pull Requests

Before submitting a PR:

- Ensure the project builds (`dotnet build`)
- Test changes locally
- Update documentation if behavior changes
- Keep commits clean and descriptive

Pull requests may be discussed or iterated on before merging.

---

## Code of Conduct

Be respectful and constructive.  
This is a learning-focused open-source project.

Thanks for contributing! 🚀
